# 🎮 **Starknet-Arcade (Arcadino)**

**Arcadino** is a fully on-chain, multi-player **GameFi** arcade built on **Starknet**, featuring a seamless, gasless gaming experience powered by **Dojo Engine**, **Cartridge Controller**, and **Starknet.dart**.

---

## 🕹️ Live Games

- 🪙 **Coin Flip** – Simple, instant win/loss mechanic with provable fairness
- 🎰 **Roulette** – European-style roulette with Starknet VRF randomness
- ✊ **Rock Paper Scissors** – Classic PvP game with real-time bet resolution
- 🐍 **Snakes & Ladders** – PvAI on-chain board game powered by Dojo Systems

Our platform offers transparent outcomes, fair gameplay, and user-first mechanics — combining decentralization with a fun-first experience.

---

## 🧱 Core Components

### 🧠 Dojo Engine
- **Snakes & Ladders** is fully implemented using **Dojo’s ECS architecture**.
- Player state, board positions, and dice rolls are all tracked as **components and systems** within **Dojo World**.
- Modular design enables future expansion into PvP or tournaments.

### 🎮 Cartridge Controller
- Used in **Coin Flip**, **Roulette**, and **Rock Paper Scissors**
- Manages **session states**, persistent player identities, and seamless in-game transaction flow.

### 📱 Starknet.dart (Mobile UX)
- All games are optimized for **mobile** using **Starknet.dart**
- Features:
  - Real-time gameplay on mobile browsers
  - Native wallet connection
  - Gasless user experience
- Plans for a full **native mobile app** with persistent login flow are underway.

---

## 🎨 Visual & Game Design

- Clean, arcade-inspired UI/UX optimized for **desktop** and **mobile**
- Each interaction (dice rolls, moves, bets, reveals) is **logged on-chain**
- Includes **animations**, **audio**, and **win/loss states** for an engaging loop

## 🔧 Technical Stack

- **Frontend**: Next.js, React, TypeScript, TailwindCSS
- **Smart Contracts**: Cairo, Dojo Systems, Starknet VRF
- **Infrastructure**: Dojo World, Cartridge Controller
- **Mobile SDK**: Starknet.dart
- **Wallets**: Argent X, Braavos
- **Hosting**: Vercel
- **DevOps**: GitHub, Cairo CLI, Starknet CLI
